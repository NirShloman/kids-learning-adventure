# Runtime music

Six user-supplied MP3 tracks, copied from the supplied files on 2026-07-29. “User-supplied” is not evidence of copyright ownership or a commercial license; all six remain blocked from public release in `docs/legal/ASSET_RIGHTS_REGISTER.csv`.

The application uses these only for background music. Hebrew narration is
provided by browser Speech Synthesis, and short interaction feedback uses the
small in-browser fallback palette; no Lyria-generated narration or effects are
deployed.
