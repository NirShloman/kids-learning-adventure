# עולמיה | Olamia

הרפתקת למידה בעברית לילדים בגילאי 3–6. אותו קוד נבנה כ־PWA וכאפליקציות Capacitor ל־Android ול־iOS. האפליקציה local-first: אין Firebase, מסד נתונים, התחברות או שירות ענן בזמן ריצה. Firebase Functions ו־Google Cloud TTS משמשים רק ב־pipeline המנהלי ליצירת קובצי קריינות שנארזים מראש.

## תוכן

המאגר כולל 3,840 יחידות תוכן בשמונה קובצי JSON תחת `src/content`:

| משחק | פריטים |
| --- | ---: |
| אותיות | 480 |
| מספרים | 480 |
| צורות | 480 |
| צבעים | 480 |
| התאמה | 480 |
| זיכרון | 480 זוגות |
| רצפים | 480 |
| מיון וסיווג | 480 |

כל משחק נטען ב־`import()` רק בעת הכניסה אליו. הבחירה מדויקת לפי גיל ורמה, מאוזנת לפי מיומנות ונמנעת מחזרה על תוכן המשחק הקודם.

## בלשי התגליות

שמונת משחקי התרגול ו״תרגול מותאם״ משתמשים בפעילויות חזותיות, רמזים, ניסיון נוסף והסבר לפני מעבר מפורש לשאלה הבאה. פתרון בעזרה חושף חלק מהתגלית; הסיכום מבחין בין הצלחה עצמאית, הצלחה בעזרה והדגמה. סבב שמור ואוסף התגליות נשמרים בנפרד לכל ילד. הקראת תשובה מופעלת בכפתור נפרד.

טבלת הגיל והרמה, תיקוני התוכן ומגבלות הביקורת מתועדים ב־[ביקורת התוכן](docs/content-review/DETECTIVE_REVIEW.md). הפקה מחדש מאפסת את אישורי הביקורת. לאחר בדיקה בפועל ועדכון התיעוד, הריצו `node scripts/record-detective-review.mjs --record-editorial-review`; זו ביקורת עריכה באמצעות AI ואינה אישור מקצועי של איש חינוך.

`npm run test:detectives` בודק 96 צירופים בטלפון ועוד 96 בטאבלט. `npm run test:detectives:offline` בודק חידוש והשלמה ללא רשת מול בניית production מקומית. נדרשת קודם `npm run build`. יצירת הקלטות בתשלום דורשת אישור נפרד לאחר הפקת רשימת החוסרים.

## העולמות החווייתיים

ארבעה עולמות צעצועים כוללים 48 משימות: בית המלאכה לאותיות, מטבח המפלצות, סדנת הצורות וגן הצבעים. בכל סבב שלוש פעילויות, עם התאמה לגיל ולרמה, הדגמות, רמזים, גרירה או בחירה בנגיעה, ואוסף יצירות נפרד לכל ילד ולכל עולם. שמירה מתבצעת לאחר שלב שהושלם; הצלחה מונחית נשמרת בנפרד מהצלחה עצמאית.

ב־PWA ניתן להכין עולם לשימוש ללא רשת ממסך בחירת המצב. האישור מוצג רק לאחר שמירת הנכסים והקריינות. בנייטיב הם נארזים באפליקציה. פרטי המימוש וההרצה נמצאים ב־[ארכיטקטורת המשחקים](docs/ADVENTURE_ARCHITECTURE.md), ב־[תסריטי הבדיקות](docs/ADVENTURE_TEST_PLAN.md) וב־[תוצאות הבדיקות](docs/ADVENTURE_TEST_RESULTS.md).

## פיתוח מקומי

```bash
npm install
npm run dev
```

סנכרון ובדיקת המעטפות הנייטיביות:

```bash
npm run mobile:assets
npm run build:native
npm run mobile:verify
```

הפרויקטים `android/` ו־`ios/` הם קוד מקור ונשמרים בריפו. אין להגדיר `server.url`: התוכן והמדיה נארזים בבינארי ופועלים ללא רשת. הוראות חתימה והעלאת בטא נמצאות ב־`docs/MOBILE_RELEASE.md`.

בדיקות ושערי איכות:

```bash
npm run validate:content
npm run test:unit
npm run typecheck
npm run test:e2e:local
npm run build
```

`npm run generate:content` מייצר מחדש את קובצי התוכן ואת `review-status.json`. כל שינוי בתוכן חייב לעבור את הסכמה, הבדיקות הסמנטיות ושלושת אישורי הביקורת.

## שמירה מקומית

ב־Web הפרופיל וההתקדמות נשמרים ב־`localStorage`. ב־Android וב־iOS הם נשמרים בקובץ אטומי באזור פרטי שאינו מגובה. בהפעלה הראשונה מתבצעת מיגרציה מהפורמט הישן, אם קיים.

## אנימציה

האפליקציה כוללת שכבת אינטגרציה עצלה ל־Rive ו־fallback מקומי. מפרט קובצי המקור נמצא ב־`src/assets/animations/README.md`. קובצי Marketplace או rigs של צד שלישי אינם מותרים.

## פריסה

```bash
npm run build:web
```

את תיקיית `dist` אפשר לפרוס ל־Cloudflare Workers & Pages ללא bindings וללא משתני סביבה. ה־Service Worker נרשם רק ב־Web; באפליקציות הנייטיביות הנכסים נטענים ישירות מהחבילה.
