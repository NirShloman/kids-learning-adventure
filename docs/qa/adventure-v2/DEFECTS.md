# Defects and corrections

The acceptance report identifies the final tested revision and results. Earlier failures below are retained as development evidence, not presented as successful acceptance runs.

| Issue / impact | Reproduction and observed failure | Correction | Verification |
|---|---|---|---|
| Narrow letter pieces / learning content | Assemble ו or י; splitting fixed font cells leaves some pieces without visible ink. | Measure real glyph ink bounds after the font loads and split the longer ink axis. | LET-01 raster checks for every segment of all 22 letters; curriculum completion. |
| Obsolete audio callback / overlapping instructions | Start playback, replace/pause it, then reject the old play promise; old cleanup can interfere with a newer instruction. | Generation-scoped callbacks and request tracking; stop detaches handlers. | Dedicated unit regression and AUDIO-01 with real local MP3 in three browser engines. |
| Keyboard activation / runtime exception | Focus a draggable piece and press Enter; Motion's synthetic pointer event has no capturable browser pointer. | Only capture trusted primary pointer events; keyboard uses the existing click path. | Keyboard rotation and console-error guard across the device matrix. |
| Secondary finger / unintended cancellation | Start a drag and cancel a different pointer ID. | Only the owning pointer can cancel or release the drag. | Real Chromium touch protocol with two fingers plus pointer cancellation/orientation tests. |
| Immediate touch measurement / test timing | Inspect the drag ghost immediately after CDP touch dispatch; React has not committed its new position. | Poll for the committed position while preserving the ≥60px lift requirement. | INT-01 passes with drag, second finger and tap alternative. |
| Landscape controls / blocked input | Use large controls in landscape with mixing or rotation. | Reposition scene controls and guide; measure every enabled target's actual hit point. | A11Y-01 / INT-03 in both orientations and seven browser/device configurations. |
| Feedback contrast / difficult to read | Show an incorrect answer on the darker lower part of a phone scene. | Add an opaque cream background behind the feedback text. | New axe check in each animated correction/hint recording plus affected visual/layout reruns. |
| Premature screenshot / incomplete evidence | Capture immediately after dismissing the intro while the lazy letter board is loading. | Wait for the interactive pieces before capture. | VIS-01 rerun; loading-placeholder images are excluded from selected evidence. |
| Development server interruption / test setup | Changing the package configuration during a dev-server run disconnects initial module requests. | Freeze the release bundle for acceptance runs and use the production preview in CI. | Fresh complete release matrix; interrupted dev run remains marked interrupted. |
| Firefox media load wait / test setup | Navigation waits for `load` while decorative media is pending, although the welcome action is present. | Wait for DOM readiness and assert the screen's actual controls. | All eight Firefox smoke scenarios passed in the focused rerun; full release regression follows. |
| Cached asset fault injection / test setup | In production, the service worker serves a prepared image despite page-level request blocking, so the intended error never occurs. | Block service workers only in the interaction/fault-injection fixture; retain dedicated real offline tests. | ERR-01 now reaches its intended failure, retries successfully and is repeated across the device matrix. |
| Suppressed worker registration / progressive enhancement | A restricted test container resolves worker registration without a registration object; accessing `update` logs a TypeError. | Leave online play available when no registration is returned. | Interaction console guards with blocked workers, plus real production offline preparation. |
| iPhone home navigation / horizontal overflow | Open the home screen with an iPhone 12 viewport; unwrapped profile/navigation controls expand document width from 390px to 422px. | Allow the navigation group to wrap inside its available width on small screens. | Welcome/menu bounds and existing-game navigation rerun across all seven browser/device configurations. |
| WebKit worker teardown / runner resource contention | The initial four-worker matrix completes assertions but two WebKit worker processes fail to exit within five minutes. | Reduce the repair run to two workers and repeat the affected WebKit scenarios with one worker. | Keep the original global errors in the scenario register; require clean remedial reports and CI runs. |
| Choice-game transition / test synchronization | During an animated transition, the status counter advances while the previous disabled answer is still in the DOM; a scripted click does nothing. | Require the current answer to be enabled before activation. | Repeat sorting and the other choice-game scenarios across browser/device configurations. |
| Compact mute switch / test setup | Clicking the visually hidden native checkbox is intercepted by its styled label. | Tap the visible label and assert that the checkbox is unchecked. | AUDIO-01, including six consecutive Android viewport reruns. |
| Queued media event / measurement | A queued `playing` event may arrive after the corresponding element has already been paused. | Count only active elements and independently sample simultaneous playback every 16ms; retain diagnostics. | AUDIO-01 requires both zero active overlaps and at most one simultaneous recording. |
| Browserslist dependency / security gate | `npm audit --omit=dev --audit-level=high` reports vulnerable transitive build packages. | Update the lockfile within compatible ranges: browserslist 4.28.9 and baseline-browser-mapping 2.11.22. | Production dependency audit reports zero vulnerabilities; rebuild and regression. |
| Decorative-symbol narration / missing audio | Synthesizing symbol-only labels produces unusable silent outputs. | Map symbols to semantic Hebrew before catalog lookup/generation, verify audio duration/checksum, publish only catalog-covered valid assets. | Strict coverage of 2,059 recordings plus playback tests. |

No assertion was dropped to hide a game defect, and no screenshot baseline was automatically accepted. An incorrect assumption about disabled-control hit testing was corrected: disabled controls still have their geometry checked; active controls must also pass hit testing.

Physical device interaction, real-device frame rate, native OS termination/relaunch and child comprehension/session duration cannot be established from these browser runs. They are explicit blocked environments in the acceptance report, not passed tests.
