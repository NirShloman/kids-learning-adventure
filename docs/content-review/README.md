# ביקורת תוכן — בלשי התגליות

המאגר כולל 3,840 פריטים המבוססים על תבניות ועובדות שנערכו מחדש. הביקורת משלבת סקירת AI של הניסוחים, המושגים והתאמת הגיל עם בדיקות משמעות לכל פריט. זו אינה קבוצת מיקוד ואינה אישור של איש מקצוע אנושי.

החלטות העריכה, גבולות הגיל והכשלים שתוקנו מתועדים ב־[DETECTIVE_REVIEW.md](DETECTIVE_REVIEW.md). יצירת תוכן מחדש מאפסת את סטטוס הביקורת; רישום ביקורת חדשה הוא פעולה נפרדת וכולל חתימה של כל פריט.
